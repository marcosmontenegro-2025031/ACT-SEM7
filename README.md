# CRUD Productos y Clientes

## Objetivo

Desarrollar un servidor HTTP utilizando TypeScript y el módulo nativo `http` de Node.js, implementando un sistema CRUD para la administración de productos y clientes. El proyecto permite realizar operaciones de creación, consulta, actualización y eliminación de registros mediante rutas HTTP que responden en formato JSON.

## Tecnologías utilizadas

- TypeScript
- Node.js
- Módulo HTTP de Node.js
- JSON
- pnpm
- PowerShell
- Postman

## Instalación

Para instalar las dependencias del proyecto, abrir una terminal PowerShell dentro de la carpeta del proyecto y ejecutar el siguiente comando:

```powershell
pnpm install
